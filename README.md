# Goodbye GripMonke
GripMonke broke recently when Gorilla Tag changed its locomotion class from GorillaLocomotion.Player to GorillaLocomotion.GTPlayer.

This is a very easy fix, but I have ultimately decided that GripMonke doesn't make much sense to exist anymore and isn't worth updating. 

It's a product of its time, an era where there were small individual mods that did one small thing. Nowadays, this kind of mod has been replaced with stuff like Grate.

GripMonke was the first thing I ever wrote in C#. It's been a long way and I've learned a lot since I first started modding 3 years ago.

I'm surprised it took this long to break. I wonder if that means my mod is the one that continued working the longest without having any updates.

# GripMonke

Mod for Gorilla Tag that disables slipping on slippery walls

![GitHub all releases](https://img.shields.io/github/downloads/lunakittyyy/GripMonke/total?style=plastic)

**REQUIRES COMPUTER INTERFACE AND UTILLA**

| Version | Supported          | Requirements               |
| ------- | ------------------ | -------------------------- |
| 2.x.x   | :white_check_mark: | Utilla, Computer Interface |
| 1.x.x   | :x:                | Computer Interface         |

Usage: Simply install the mod, Computer Interface, and Utilla then go into a modded lobby. The mod will not work if you aren't in a modded lobby first. Enable and disable the mod from the Mod Status menu.
